# Performance Optimization Review

## Identified Optimization Opportunities

1. **Issue 1:** 
   - **Description:** No message for the product which are not in the inventory.
   - **Proposed Solution:** We can display a message product not found if their search does not matches with any product of that category
   - **Benefits:** This is going to help the customers to understand we do not have the product that they are searching for.

2. **Issue 2:** 
   - **Description:** The overall view of the website is very basic and has a very lame design.
   - **Proposed Solution:** We can try to design this website in some colourful theme swith amazing UI/UX features for easy access to the website.
   - **Benefits:** This will going to attract customers with the colourful theme of the website and force them to go through the website.

3. **Issue 3:** 
   - **Description:** The size of the images are not the same. Some are very big while some are very smaller as compared to others.
   - **Proposed Solution:** We can try to customize the size of the images such that all the images have the same size. Also try to display atleast 3 product cards in a single line. 
   - **Benefits:** This will hep the customers to view many product cards at one go which will provide them various options to choose.

4. **Issue 4:** 
   - **Description:** There should be table like bill that need to be there under the shopping cart section. 
   - **Proposed Solution:** we can create a table that consist of the product name, number of products and their total price.
   - **Benefits:** This will help the customer to keep track of each and every product that they are going to buy.

5. **Issue 5:** 
   - **Description:** There should be some direct tabs which can can show only those products of that kind.
   - **Proposed Solution:** we can try creating direct tabs like clothes section, electronics section, jewellary section and etc rather than using the filter category option.
   - **Benefits:** This will help the customer to direct view the products that they demand rather than selecting the category from the filter option.
